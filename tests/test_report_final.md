## 三、发现的问题与修复

### 3.1 已修复问题

#### 问题1: `can_convert_to_float` 函数未处理 `TypeError`
**位置**: `app/core/mos_calculator.py:111-119`

**问题描述**: 当传入 `None` 时，函数抛出 `TypeError` 而不是返回 `False`。

**修复方案**:
```python
# 修复前
try:
    float(x)
    return True
except ValueError:
    return False

# 修复后
try:
    float(x)
    return True
except (ValueError, TypeError):
    return False
```

#### 问题2: `httpx` 版本与 `starlette` 不兼容
**位置**: 测试框架依赖

**问题描述**: `httpx 0.28.1` 与 `starlette 0.27.0` 不兼容，导致 `TestClient` 初始化失败。

**修复方案**: 降级 `httpx` 到 `0.27.2` 版本。

```bash
pip install 'httpx>=0.24.0,<0.28.0'
```

#### 问题3: 旧测试文件使用错误密码
**位置**: `tests/backend/test_api.py`

**问题描述**: 测试中使用了错误的默认密码 `admin123`，正确密码应为 `tp123456`。

**修复方案**: 更新测试用例中的密码。

### 3.2 已知限制（跳过测试的原因）

1. **模型依赖不可用**: 部分测试需要特定的深度学习模型（如NISQA的完整库），这些模型未安装时会跳过。
2. **硬件依赖**: 部分测试需要CUDA支持，在无GPU环境会跳过。
