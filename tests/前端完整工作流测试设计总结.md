### ✅ 测试40: MOS评分完整工作流
**测试名称**: `test_mos_complete_workflow_upload_process_download`

**完整流程**（7个步骤）：
```
1. 登录认证
   → 使用admin账号登录系统
   
2. 切换到MOS评分Tab
   → 点击MOS评分Tab激活
   
3. 上传音频文件
   → 查找上传入口（支持多种选择器）
   → 上传测试音频文件（workflow_test.wav）
   → 等待上传完成
   
4. 提交处理任务
   → 文件上传后自动触发后端处理
   
5. 监控处理进度
   → 查找进度指示器
   → 验证进度条/状态更新
   → 观察WebSocket实时推送
   
6. 查看评分结果
   → 等待后台处理完成
   → 查找结果显示区域
   → 验证MOS评分表格显示
   
7. 下载结果报告
   → 点击下载按钮
   → 监听下载事件
   → 验证Excel文件下载成功
```

**验证点**：
- ✅ 文件上传成功
- ✅ 任务创建成功
- ✅ 进度实时更新
- ✅ 结果正确显示
- ✅ 报告下载成功
