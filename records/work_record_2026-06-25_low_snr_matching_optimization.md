# 低信噪比音频匹配对齐优化

**日期:** 2026-06-25 更新: 2026-06-26
**作者:** zhouchenghao
**状态:** 完成

## 问题背景

使用MOS分计算系统对"拾音距离"测试素材（1m-10m，48kHz，~55s）进行匹配切分时，远距离低SNR音频匹配成功率极低。

### 测试素材特征

| 文件 | SNR | RMS | 说明 |
|------|-----|------|------|
| dut_1m_降噪关 | 16.1dB | 0.092 | 1m设备录音，高SNR |
| dut_3m_降噪关 | 10.8dB | 0.061 | 中距离 |
| dut_5m_降噪关 | 8.1dB | 0.029 | 中远距离 |
| dut_10m_降噪关 | 9.6dB | 0.022 | 远距离，信号弱 |
| dut_10m_降噪开 | 0.0dB | 0.012 | 远距离+降噪后弱信号 |

参考音频（ref_001.wav～ref_004.wav）：每个~12s，16kHz，干净同内容参考段

## 根因分析

### 问题：指纹匹配（Shazam）在噪声中完全不可靠

详细测试发现：
1. **所有SNR水平的测试音频，指纹匹配的偏移量均为0.00s**（错误的）
2. **置信度极低**（0.05-0.12），即使SNR=16dB也如此
3. 指纹hash匹配数量太少（10-42个），不足以确定正确偏移
4. **预增强处理不能改善指纹匹配**（甚至减少可检测峰值数量）

```
原始指纹匹配结果 (16dB SNR):
  ref_004.wav @ 0.00s conf=0.052 hash=16  ← 错误! 应为42.88s
  ref_003.wav @ 0.00s conf=0.031 hash=11  ← 错误! 应为29.73s
```

### DTW工作但搜索窗口受限

**DTW（MFCC+余弦距离）本身在全范围搜索时工作正确**，即使SNR=0dB也能找到所有4个参考段的正确偏移：

```
10m降噪开 (0dB SNR):
  ref_001 @ 1.63s ✓   ref_002 @ 14.88s ✓
  ref_003 @ 28.64s ✓  ref_004 @ 42.72s ✓
```

但原管道将DTW搜索限制在指纹结果±5s窗口内（指纹输出offset=0），导致DTW搜索[0,5]s而非[0,55]s。

### 关键技术决策

- Shazam指纹算法不适用于远场低SNR场景
- DTW（MFCC+余弦距离+CMVN）在噪声下仍保持有效
- 正确的方案：**跳过指纹，直接全范围DTW扫描**

## 优化方案实施

### 核心策略变更

**从 "指纹为主，DTW精修" 改为 "全范围DTW为主，指纹为辅助预筛查"**

| 阶段 | 原方案 | 新方案 |
|------|--------|--------|
| 预增强 | 无 | Wiener滤波（SNR改善+10.4dB） |
| 匹配方案 | Shazam指纹→限制DTW窗口 | **全范围两级DTW扫描** |
| 噪声回退 | 无 | 自适应CMVN+余弦距离 |
| 置信度过滤 | 无（接受offset=0结果） | confidence≥0.3才接受 |

### 修改的文件

| 文件 | 改动 |
|------|------|
| `app/core/matching_optimizer.py` | **重构**: 新增_full_range_dtw_sweep()全范围DTW扫描；重写match_with_fallback()以DTW为主方案 |
| `app/core/calculator/mos_calculator.py` | get_ref_file_by_content增加置信度阈值过滤（conf≥0.2且hash≥10才接受指纹结果），低质指纹结果自动回退到优化匹配 |

### 删除/废弃

- `app/core/matching_optimizer.py`中的_match_with_fallback Level1指纹匹配（已废弃，但保留代码）
- EmbeddingMatcher（TCF模型）回退方案未实际需要（DTW已解决所有场景）

### 处理耗时

- 全范围DTW扫描：**~2.2-2.3s/文件**（55s测试音频，4个参考段）
- 包括音频加载、MFCC提取、粗扫+精扫两级搜索
- 可接受（原指纹方案在失败时更快但无效）

### 完整集成测试

`get_ref_file_by_content()` 完整调用链验证成功：

1. 文件名匹配 → 全部失败（dut_* vs ref_*）
2. 指纹匹配 → 置信度不足（conf<0.2），触发回退
3. 优化匹配 → **全部成功**（DTW全范围扫描，准确偏移）

## 关键技术细节

### 两级DTW搜索

```
Level 1 - 粗扫描：大步长覆盖全范围
  - 步长: ~总帧数/15
  - 目标: 定位大致位置
  - 耗时: ~1.5s

Level 2 - 精细搜索：小步长精修
  - 步长: 3帧
  - 范围: 粗扫描结果±3秒
  - 耗时: ~0.5s
```

### 置信度评估

基于归一化DTW距离（距离/参考帧数）：
- <0.5 → 0.9（极好匹配）
- <1.0 → 0.7（好匹配）
- <2.0 → 0.5（可接受匹配）
- <4.0 → 0.3（边缘匹配）
- <6.0 → 0.15（弱匹配，可尝试但不保证准确）

## 后续优化方向

1. **特征优化**: 尝试GFCC/Gammatone特征替代MFCC，进一步提升噪声鲁棒性
2. **速度优化**: 使用向量化DTW或快速NN算法加速全范围扫描
3. **自适应步长**: 根据SNR动态调整粗扫描步长，低SNR使用更多步数
4. **多候选跟踪**: 当前返回conf最高的单个匹配，可扩展为检测音频中多次出现同一参考
