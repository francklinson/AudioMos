ASR API 接口文档
1. 语音识别接口
POST /api/asr/v1/recognize
支持 X-API-Key 头认证 或 JWT Bearer Token
参数类型必填说明
audio_fileFile是音频文件(.wav/.mp3)
algorithmString否算法名称，默认 paraformer-large
languageString否语言代码，默认 zh
2. 算法列表接口
GET /api/asr/v1/algorithms
无需认证
3. 请求示例
curl -X POST http://HOST:PORT/api/asr/v1/recognize \
  -H "X-API-Key: your-api-key" \
  -F "audio_file=@test.wav" \
  -F "algorithm=paraformer-large"
4. 响应示例
{
  "text": "今天天气真好",
  "language": "zh",
  "rtf": 0.03,
  "processing_time": 0.42,
  "segments": [
    {"start": 0.0, "end": 0.8, "text": "今天"},
    {"start": 0.8, "end": 1.5, "text": "天气真好"}
  ]
}
