POST /api/auth/login

用户登录并获取 JWT Token。Token 有效期由服务端配置决定。

请求参数
参数类型必填说明
usernameString是用户名（OAuth2 form-data 格式）
passwordString是密码
响应
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer"

示例
curl -X POST {BASE}/api/auth/login \
  -F "username=admin" \
  -F "password=admin123"

curl -H "Authorization: Bearer <token>" {BASE}/api/auth/me
POST /api/auth/logout JWT

用户登出，服务端记录登出日志。

响应
{"message": "登出成功"}
MOS 评分

MOS（Mean Opinion Score）评分系统：上传音频 → 提交任务 → 轮询/WebSocket 获取进度 → 下载 Excel 报告。

POST /api/mos/upload

上传音频文件（支持批量），返回 task_id 用于后续操作。

请求参数（multipart/form-data）
参数类型必填说明
filesFile[]是音频文件列表，支持 .wav/.mp3/.flac 等格式
metricsString(JSON)否可选评分指标配置，JSON 字符串
响应
{
  "task_id": "uuid-string",
  "message": "上传成功",
  "file_count": 3
}
POST /api/mos/process/{task_id}

提交 MOS 评分任务到计算队列。上传完成后必须调用此接口开始评分。

路径参数
参数说明
task_id上传接口返回的任务 ID
GET /api/mos/tasks/{task_id}

获取单个任务状态和结果。任务完成后 response 中包含完整评分数据。

响应字段
字段类型说明
task_idString任务唯一标识
statusStringqueued / processing / completed / failed
progressInt进度百分比 0-100
messageString当前步骤描述
resultsObject[]评分结果列表（完成后）
processing_timeFloat处理耗时（秒）
其他端点
方法路径说明认证
GET/api/mos/tasks获取当前用户所有任务列表（分页）JWT
GET/api/mos/results/{task_id}获取任务详细评分结果数据JWT
GET/api/mos/download/{task_id}下载评分结果 Excel 文件JWT
GET/api/mos/audio/{task_id}/{filename}获取原始音频（试听），支持 ?token= 查询参数Token
DELETE/api/mos/tasks/{task_id}删除任务及关联文件JWT
GET/api/mos/performance获取 MOS 计算性能统计JWT
WS/api/mos/ws/{task_id}WebSocket 实时进度推送（公开）公开
典型调用流程
# 1. 登录获取 token
TOKEN=$(curl -s -X POST {BASE}/api/auth/login -F "username=admin" -F "password=admin123" | jq -r '.access_token')

# 2. 上传音频
TASK_ID=$(curl -s -X POST {BASE}/api/mos/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@audio1.wav" -F "files=@audio2.wav" | jq -r '.task_id')

# 3. 提交处理
curl -X POST {BASE}/api/mos/process/$TASK_ID -H "Authorization: Bearer $TOKEN"

# 4. 轮询任务状态直到 completed
curl -s {BASE}/api/mos/tasks/$TASK_ID -H "Authorization: Bearer $TOKEN" | jq '.status'

# 5. 下载 Excel 报告
curl -o result.xlsx {BASE}/api/mos/download/$TASK_ID -H "Authorization: Bearer $TOKEN"

TASK_ID=$(curl -s -X POST {BASE}/api/restoration/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@noisy.wav" -F "algorithm=denoiser" | jq -r '.task_id')

curl -X POST {BASE}/api/restoration/process/$TASK_ID -H "Authorization: Bearer $TOKEN"

# 等待完成后下载
curl -o restored.wav {BASE}/api/restoration/download/$TASK_ID -H "Authorization: Bearer $TOKEN"

# 批量修复（一步完成）
curl -X POST {BASE}/api/restoration/batch/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@a.wav" -F "files=@b.wav" -F "algorithm=denoiser"

ASR 语音识别

Automatic Speech Recognition：语音转文字、算法对比评测（Benchmark）、公开测评榜单。

第三方调用接口（外部 API）
POST /api/asr/v1/recognize X-API-Key / JWT

核心识别接口：上传音频文件，同步返回转写结果。支持 X-API-Key 或 JWT Bearer Token 两种认证方式。

请求参数（multipart/form-data）
参数类型必填默认值说明
audio_fileFile是-音频文件，支持 .wav/.mp3/.flac 等
algorithmString否paraformer-largeASR 算法名称
languageString否zh语言代码（zh/en）
响应
{
  "text": "今天天气真好适合出去散步",
  "language": "zh",
  "rtf": 0.0342,
  "processing_time": 0.891,
  "segments": [
    {"start": 0.0, "end": 1.2, "text": "今天天气真好", "confidence": 0.98},
    {"start": 1.2, "end": 2.8, "text": "适合出去散步", "confidence": 0.95}
  ]
}
示例
# 使用 X-API-Key 认证
curl -X POST {BASE}/api/asr/v1/recognize \
  -H "X-API-Key: your-api-key" \
  -F "audio_file=@speech.wav" \
  -F "algorithm=paraformer-large" \
  -F "language=zh"

# 使用 JWT 认证
curl -X POST {BASE}/api/asr/v1/recognize \
  -H "Authorization: Bearer <token>" \
  -F "audio_file=@speech.wav"

转写任务（Web 端使用）
POST /api/asr/transcribe

上传单个音频文件创建转写任务。返回 task_id，通过 WebSocket 或轮询获取结果。

请求参数（multipart/form-data）
参数类型必填说明
audio_fileFile是音频文件
algorithmString否ASR 算法名称
languageString否语言代码（zh/en），默认 zh
reference_textString否参考文本（用于自动计算 CER）
POST /api/asr/transcribe/batch

批量上传多个音频文件进行转写。

请求参数
参数类型必填说明
filesFile[]是多个音频文件
algorithmString否ASR 算法名称
reference_textsString(JSON)否参考文本 JSON 字符串
任务管理端点
方法路径说明认证
GET/api/asr/algorithms获取所有算法及初始化状态JWT
POST/api/asr/algorithms/{name}/initialize初始化/加载算法模型到内存JWT
POST/api/asr/algorithms/{name}/unload卸载算法释放 GPU 显存JWT
GET/api/asr/tasks获取当前用户所有转写任务JWT
GET/api/asr/tasks/{task_id}获取任务状态与转写结果JWT
POST/api/asr/tasks/{task_id}/cancel取消正在执行的任务JWT
DELETE/api/asr/tasks/{task_id}删除任务及关联文件JWT
典型调用流程
TOKEN=$(curl -s -X POST {BASE}/api/auth/login -F "username=admin" -F "password=admin123" | jq -r '.access_token')

# 初始化算法
curl -X POST {BASE}/api/asr/algorithms/paraformer-large/initialize \
  -H "Authorization: Bearer $TOKEN"

# 上传转写
TASK_ID=$(curl -s -X POST {BASE}/api/asr/transcribe \
  -H "Authorization: Bearer $TOKEN" \
  -F "audio_file=@speech.wav" \
  -F "algorithm=paraformer-large" \
  -F "reference_text=今天天气真好" | jq -r '.task_id')

# 轮询结果
while true; do
  STATUS=$(curl -s {BASE}/api/asr/tasks/$TASK_ID -H "Authorization: Bearer $TOKEN" | jq -r '.status')
  if [ "$STATUS" = "completed" ]; then break; fi
  sleep 1
done

# 获取转写文本
curl -s {BASE}/api/asr/tasks/$TASK_ID -H "Authorization: Bearer $TOKEN" | jq '.result.text'
Benchmark 测评
POST /api/asr/benchmark/run

启动 ASR 算法 Benchmark 评测。已评测过的（算法+数据集）组合会自动读取缓存，不重复计算。

请求体 (JSON)
{
  "algorithms": ["paraformer-large", "sensevoice-small"],
  "dataset": "builtin",
  "max_samples": 100,
  "metrics": ["cer", "wer", "rtf"]
}
字段类型必填说明
algorithmsString[]是待评测的算法名称列表
datasetString是数据集标识（如 builtin/aishell1_test）
max_samplesInt否最大评测样本数，默认 100
metricsString[]否评测指标，默认 ["cer","wer","rtf"]
Benchmark 端点
方法路径说明认证
GET/api/asr/datasets获取可用评测数据集列表JWT
GET/api/asr/benchmark获取所有 Benchmark 列表JWT
GET/api/asr/benchmark/{bench_id}获取 Benchmark 状态与结果JWT
GET/api/asr/benchmark/{bench_id}/ranking获取 Benchmark 排名JWT
GET/api/asr/benchmark/{bench_id}/report下载评测报告（支持 ?token= & ?format=json）Token
Benchmark 调用示例
# 启动测评
BENCH_ID=$(curl -s -X POST {BASE}/api/asr/benchmark/run \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"algorithms":["paraformer-large"],"dataset":"builtin","max_samples":50}' | jq -r '.bench_id')

# 轮询状态
curl -s {BASE}/api/asr/benchmark/$BENCH_ID -H "Authorization: Bearer $TOKEN" | jq '{status,progress}'

# 下载报告
curl -o report.json "{BASE}/api/asr/benchmark/$BENCH_ID/report?token=$TOKEN&format=json"
